Mega Overhaul Update

Main additions after the continued overhaul:
- Card upgrade system:
  * Rest site can upgrade a random card.
  * Upgraded cards show a + in their names.
  * Upgraded cards have stronger values and updated descriptions.
- Rest site is now an actual choice screen:
  * Rest: heal 30% max HP.
  * Upgrade: upgrade a random card.
  * Train: gain +1 max energy, lose 4 max HP.
- Victory screen:
  * Defeating the boss now ends the run instead of opening a normal reward screen.
  * Press R to restart after victory.
- Deck viewer:
  * Press D to open/close the deck view.
  * Deck view shows upgraded cards correctly.
- Run statistics:
  * Floors cleared
  * Combats won
  * Enemies defeated
  * Gold spent
  * Cards played
- Shop now tracks gold spent.
- Game Over screen now shows run stats.
- Top bar now shows floor, deck size, upgrades, potions, and relics.

Controls:
- E: end turn / leave reward/shop/event/rest/deck
- D: deck view
- P: use first potion
- Number keys: select card / use potion slot
- M: map toggle
- R: restart after death or victory

Install:
1. Replace your current sketch.js with this sketch.js.
2. Copy the assets folder into your project.
3. Keep your own assets/audio folder if you use custom music/sounds.
